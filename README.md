## Execução

Para executar localmente o projeto você precisa de um gerenciadore de pacotes, usei o [npm](https://www.npmjs.com/package/download) no exemplo.

Primeiro deve executar o comando abaixo e esperar o gerenciador instalar as dependencias localmente.

```bash
npm install
```

Após terminado execute o comando abaixo e tudo deve funcionar e o site deve estar em [localhost:3000](http://localhost:3000/).

```bash
npm run dev
```
