O processo de desenvolvimento de um banco de dados sem dúvidas é uma das etapas mais importantes, afinal ter uma arquitetura mal desenhada impacta diretamente na performance do sistema.

Nesse artigo vamos passar por todas as etapas de elaboração de um banco de dados, representando o mais fielmente possível do tema proposto: "Instituição acadêmica".

# Análise de requisitos

A primeira etapa foi a análise de requisitos, que é fundamental para o desenvolvimento de qualquer sistema, pois é nela que vamos entender o que o cliente precisa e como podemos atender essas necessidades.

- **Definição do escopo:** Analisamos o escopo do projeto e definimos o que será feito e o que não será feito.
- **Documentação dos requisitos:** Documentamos os requisitos funcionais e não funcionais do sistema.

## Definindo o escopo

O escopo do projeto é a definição do que será feito e o que não será feito, ou seja, é a definição do que o sistema vai fazer e o que ele não vai fazer.

### O que será feito

- Cadastro de alunos.
- Cadastro de funcionários.
- Cadastro de professores (Entidade separada).
- Cadastro de cursos.
- Cadastro de disciplinas.
- Cadastro de notas.

### O que não será feito

- Sistema de gestão financeira.
- Sistema de controle de estoque.
- Módulo de gerenciamento de recursos humanos.

## Documentação dos requisitos

A documentação dos requisitos é a etapa onde vamos documentar os requisitos funcionais e não funcionais do sistema.

### Requisitos funcionais

Os requisitos funcionais são os requisitos que definem o que o sistema deve fazer.

**Cadastro de Alunos:**

- O sistema deve permitir o cadastro de informações dos alunos, incluindo nome, matrícula, data de nascimento, endereço e contato.
- Deve ser possível associar os alunos a cursos e disciplinas.

**Cadastro de Funcionário:**

- O sistema deve permitir o cadastro de informações dos funcionários, incluindo nome, número de registro, cargo e dados de contato.
- Caso o funcionário seja um professor deve relacionar a entidade ao funcionário, com informações como área de especialização.
- Deve ser possível atribuir disciplinas aos professores.

**Cadastro de Cursos:**

- O sistema deve possibilitar o registro de informações sobre os cursos oferecidos pela instituição, incluindo nome do curso e descrição.

**Cadastro de Disciplinas:**

- Deve ser possível cadastrar informações sobre as disciplinas, incluindo nome da disciplina e professor responsável.

**Cadastro de Notas:**

- O sistema deve permitir que os professores insiram notas dos alunos para cada disciplina.
- Deve calcular automaticamente a média das notas e atualizar o desempenho do aluno.

### Requisitos não funcionais

**Segurança:**

- O sistema deve garantir a segurança dos dados dos alunos e professores, com acesso restrito a usuários autorizados.

**Disponibilidade:**

 - O sistema deve estar disponível 24/7, com manutenções programadas realizadas fora do horário de maior uso.

**Escalabilidade:**

- O sistema deve ser escalável para acomodar o crescimento futuro da instituição, permitindo a adição de novos cursos, disciplinas e alunos.
